# 网络信息内容生态治理规定

本文依据国家互联网信息办公室令第5号《网络信息内容生态治理规定》整理。规定自2020年3月1日起施行，重点规范网络信息内容生产者、网络信息内容服务平台和网络信息内容服务使用者的行为。

[法规概览](#overview) · [安全要求与实施](#requirements) · [法规原文](#reference)

## 法规概览 {#overview}

| 项目 | 内容 |
| --- | --- |
| 法规 | 《网络信息内容生态治理规定》（国家互联网信息办公室令第5号） |
| 生效日期 | 2020年3月1日 |
| 主要适用对象 | 网络信息内容生产者、网络信息内容服务平台、网络信息内容服务使用者及相关行业组织 |
| 核心问题 | 违法和不良信息治理、平台主体责任、内容审核、推荐机制、账号管理、广告审核、投诉举报、年度报告 |
| 官方来源 | [中国网信网](https://www.cac.gov.cn/2019-12/20/c_1578375159509309.htm) |

下文按 **“法规要求 → 落实与验收”** 展开：每项要求同时说明实施动作与可验证证据。算法推荐、深度合成、公众账号、跟帖评论等具体业务，还应同时适用对应专项规定。

## 安全要求与实施 {#requirements}

| 核心主题 | 达成状态 |
| --- | --- |
| 内容标准 | 违法、不良和鼓励类信息有清晰、可执行的分类口径 |
| 平台治理机制 | 注册、发布、评论、推荐、巡查、应急和黑产处置形成闭环 |
| 推荐与重点位置 | 热榜、推荐、搜索、弹窗等高曝光位有更严格控制 |
| 账号与互动治理 | 账号、群组、评论和互动行为可识别、可限制、可追责 |
| 投诉举报与留痕 | 举报入口可用，处置和证据可追溯 |
| 年度治理报告 | 平台治理结果有可复核的数据和负责人履职记录 |

### 把法规中的内容分类转化为内部可执行标准

**法规要求｜第5至7条。** 规定区分鼓励制作传播的信息、不得制作传播的违法信息，以及应当防范和抵制的不良信息。平台不能只维护一份抽象政策，而需要把不同性质的信息映射到具体产品处置动作。

**落实与验收。**

- 建立统一内容分类体系，明确违法信息、不良信息及其他风险内容的定义、示例和处置方式。
- 对文本、图片、音视频、直播、评论、弹幕、账号资料、链接和搜索词等不同载体建立对应识别能力。
- 政策调整后，同步更新机器模型、人工审核手册、申诉规则和运营策略。
- 对难以机械判断的语境类问题建立人工升级和案例库，避免审核口径长期漂移。

**验收证据。**

- 给不同审核员同一批边界案例，判断和处置结果是否一致？
- 最新规则变更后，模型、审核手册和申诉口径分别何时更新？
- 同一内容换成图片、谐音、缩写或视频字幕后，风险识别是否仍然有效？
- 是否存在只在发布侧审核、评论和私信等入口长期遗漏的情况？

### 建立完整的平台内容治理机制

**法规要求｜第8、9条。** 网络信息内容服务平台应履行内容管理主体责任，建立网络信息内容生态治理机制和治理细则，健全用户注册、账号管理、信息发布审核、跟帖评论审核、版面页面生态管理、实时巡查、应急处置、网络谣言和黑色产业链信息处置等制度，并设置治理负责人、配备相适应的专业人员。

**落实与验收。**

- 将治理责任拆到具体产品域和责任人，而不是只由一个中央审核团队承担。
- 账号、发布、评论、搜索、推荐、热榜、群组、直播、广告等场景都应有明确治理策略。
- 建立实时巡查与专项巡查机制，对突发事件、热点话题和异常传播速度提高处置等级。
- 内容治理人员、模型和外包审核能力应与业务规模匹配，并有培训、质检和绩效反馈机制。

**验收证据。**

- 从一个新功能上线记录看，是否经过内容安全评审？
- 业务高峰或突发热点时，审核积压是否会突破风险阈值？
- 外包审核团队是否使用与内部一致的规则、培训和质检标准？
- 治理负责人是否能拿出近一季度重大内容风险和改进情况，而不只是制度文件？

### 对违法和不良信息实施发现、处置、留痕和报告闭环

**法规要求｜第10条。** 平台不得传播违法信息，应防范和抵制不良信息；发现相关信息时，应依法立即采取处置措施，保存有关记录，并向有关主管部门报告。

**落实与验收。**

- 处置动作按风险区分停止传播、删除、屏蔽、限制推荐、断链、账号限制等层级。
- 内容、账号、设备、IP、传播链路、举报、审核结论和处置动作形成统一事件记录。
- 对需要向主管部门报告的情形，建立识别标准、报告模板和责任人。
- 对高传播量或高危内容开展传播链追溯，避免只删除原帖而保留大量转载。

**验收证据。**

- 抽取一个重大内容事件，能否还原首次发布、传播、发现、审核、处置和报告完整时间线？
- 已删除内容的转载、二创和截图是否同步处置？
- 同一账号重复发布相似违规内容时，是否触发升级而不是每次单独删帖？
- 保存的处置记录能否支撑后续申诉、监管核查和内部复盘？

### 对推荐、热榜、搜索、弹窗等重点位置实施更严格治理

**法规要求｜第11、12条。** 平台应加强版面页面生态管理，重点位置不得呈现规定中的不良信息；采用个性化算法推荐技术推送信息时，应设置符合内容治理要求的推荐模型，并建立人工干预和用户自主选择机制。

**落实与验收。**

- 将首页首屏、热搜、榜单、弹窗、推荐区、搜索联想等定义为高曝光位置并采用更高审核阈值。
- 推荐系统的召回、排序、热度、用户反馈和人工运营策略均纳入内容风险控制。
- 对高风险内容设置“不可推荐”或“降权”硬约束，不能完全依赖事后人工删除。
- 建立人工干预记录，明确谁、基于什么规则、在什么时间修改了推荐或榜单结果。

**验收证据。**

- 一条不良信息即使未达到删除标准，是否仍可能进入热榜或推荐流？
- 推荐模型升级后是否进行内容安全回归测试？
- 人工修改榜单或热搜是否有权限隔离和审计记录？
- 用户关闭个性化推荐等自主选择能力是否真实有效？

### 把账号、群组和异常互动行为纳入生态治理

**法规要求｜第15条及第四章相关条款。** 平台应制定并公开管理规则和平台公约，建立用户账号信用管理制度；网络信息内容服务使用者、生产者和平台不得通过人工或技术手段实施流量造假、流量劫持、虚假注册账号、非法交易账号、操纵用户账号等破坏网络生态秩序的行为。

**落实与验收。**

- 账号注册、认证、登录、改名、交易、找回和封禁全生命周期建立风控规则。
- 对刷量、控评、批量账号、自动化发布、恶意引流等行为建立跨账号和跨设备关联检测。
- 群主、版主和社区管理者的权限与责任清晰，对高风险群组实施更高频巡查。
- 账号信用应真实影响服务能力，如发布频率、推荐范围、商业化能力或审核强度。

**验收证据。**

- 一个被封禁账号能否通过相同设备、手机号或关联身份快速重新注册？
- 流量异常是否只作为反作弊问题处理，还是会同步评估内容生态风险？
- 账号信用分是否真正影响策略，还是只有展示没有控制作用？
- 对批量注册和自动化操纵行为，系统能否识别团伙而不只是单账号异常？

### 广告和商业化内容也必须进入同一治理体系

**法规要求｜第14条等。** 平台应加强对广告位和平台展示广告内容的审核巡查，对违法广告依法处理；同时不得通过内容呈现干预侵害他人合法权益或谋取非法利益。

**落实与验收。**

- 商业广告、原生广告、达人营销、带货内容和付费置顶统一纳入内容治理范围。
- 商业化目标不能覆盖内容安全策略，广告客户和高价值账号不得拥有审核豁免。
- 建立广告主、素材、落地页和实际投放内容的一致性检查。

**验收证据。**

- 已通过审核的广告投放后更换落地页，是否会重新触发检查？
- 高收入广告主违规时是否与普通用户执行同一基本规则？
- 原生内容和商业推广之间是否有识别与审核差异导致治理盲区？

### 投诉举报和年度报告应有可核验的数据闭环

**法规要求｜第16、17条。** 平台应在显著位置设置便捷投诉举报入口，及时受理处置并反馈；同时应编制网络信息内容生态治理工作年度报告，包括治理工作、负责人履职和社会评价等内容。

**落实与验收。**

- 投诉举报入口覆盖内容、账号、评论、群组、广告等主要对象，并允许用户跟踪结果。
- 举报数据与机器识别、人工审核和账号处罚数据打通，用于发现规则缺口。
- 年度报告中的处置量、申诉量、整改情况等指标应能从后台系统复算。
- 重大治理问题形成机制性改进项，并跟踪到产品和策略完成上线。

**验收证据。**

- 从用户端完成一次举报需要几步，是否存在入口隐蔽或分类困难？
- 同一类举报持续上升时，是否推动规则或产品改进？
- 年度报告中的关键数据与后台原始记录能否一致复算？
- 负责人履职是否有会议、决策、专项治理和整改闭环证据？
