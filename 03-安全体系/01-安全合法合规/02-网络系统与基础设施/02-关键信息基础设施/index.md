# 关键信息基础设施安全保护体系

关基安全不是替代等级保护的一套体系，而是在等级保护等基础制度之上，对依法认定的关键信息基础设施实施重点保护。实践中应把**认定与边界 → 安全保护 → 密码 → 供应链 → 监测预警 → 主动防御 → 检测测评 → 事件处置 → 持续整改**串成闭环。

## 与等级保护的关系

**等保是普遍安全基线，关基是在此基础上的重点保护。** GA/T 2182明确会结合等级测评结果进行关基测评分析。因此，被认定为关基后不是“用39204替代等保”，而是增加关基特有的组织责任、重点保护、供应链、检测评估、监测预警和主动防御要求。

## 企业落地路径

1. **认定与边界：**保存认定信息，建立关键业务、系统、网络、数据、第三方和基础资源之间的边界及依赖关系。
2. **安全保护：**以GB/T 39204为核心建立关基控制基线，与等保、数据安全、密码和供应链控制去重映射。
3. **密码：**对照关基商密规定及GM/T 0133形成密码应用方案、建设、运行和密评闭环。
4. **监测与主动防御：**覆盖互联网及隔离边界、第三方接入、数据中心、终端、云等关键位置，并持续验证攻击发现和阻断能力。
5. **检测测评：**结合等级测评结果，按照GA/T 2182开展关基专项测评；问题进入统一整改与复测。
6. **供应链：**管理关键产品服务、远程运维、更新、停服/EOL、控制权和替代能力。
7. **事件处置：**与国家网络安全事件、行业监管报告和企业应急响应联动，保留完整时间线和证据。

## 使用原则

正式发布的法规和标准作为现行依据；尚在制定中的标准项目只用于架构预研和差距分析，并明确标记状态。
