# 法规关系、时间与责任索引

本页集中保存法规关系、时间与责任条件。业务适用和统一治理模型见[安全合法合规总览](./01-安全合法合规.md)。目录整理与内容编辑不代表重新审查全部条款，具体案件须结合行为时间、主体和正式文本判断。

## 法规关系与适用顺序 {#legal-map}

### 效力层级与主题关系分别看

国家层面的法律效力高于行政法规，行政法规高于部门规章，依据[《立法法》第99条][src-legislation]。法律、法规、规章以外的其他规范性文件不得设定行政处罚，依据[《行政处罚法》第16条][src-administrative-penalty]。

| 层级 | 本目录代表文件 | 需要确认的关系 |
| --- | --- | --- |
| 法律 | 网络安全法、数据安全法、个人信息保护法、国家安全法、密码法、电子签名法、反电信网络诈骗法 | 处于同一效力层级；不能将国家安全法画成效力高于其他法律的一层 |
| 行政法规 | 网络数据安全管理条例、关基保护条例、商用密码管理条例、未成年人网络保护条例、互联网信息服务管理办法 | 由国务院制定，在法律框架内细化制度；名称为“办法”不改变其层级 |
| 部门规章 | 网络安全审查办法、数据出境安全评估办法、个人信息合规审计办法、人民银行3号令和4号令等 | 依制定机关、职权与范围适用，不因专项就自动优先于法律 |
| 行政规范性文件 | 漏洞管理规定、国家网络安全事件报告办法、AI标识办法、银行保险机构数据安全办法等 | 实施和监管要求；责任须追溯有权设定处罚的依据 |

文件名称不能单独决定层级。本页没有完整展开地方性法规、地方政府规章和技术标准，涉及属地及行业特殊要求时另行核验。

### 交叉适用与专项衔接

[网络安全法][src-csl]聚焦网络运行、产品、关基与应急；[数据安全法][src-dsl]覆盖数据处理及保护；[个人信息保护法][src-pipl]聚焦个人信息处理合法性、权益与处理者责任。同一系统可以同时适用。

| 主题 | 阅读关系 |
| --- | --- |
| 网络与系统 | 网络安全法 → 关基、采购审查、漏洞和事件专项规则 |
| 数据与个人信息 | 三部基础法律 → 网络数据安全管理条例 → 风险评估、审计、人脸等专项规则 |
| 数据跨境 | 基础法律和条例 → 跨境流动规定 → 评估、合同或认证路径 |
| 平台与AI | 网络、数据、个人信息及互联网服务要求 → 内容、算法、合成、标识、未成年人等专项规则 |
| 密码与可信身份 | 密码法 → 商用密码法规、密评与关基商密要求；电子签名另核效力和认证责任 |
| 行业 | 根据支付、银行保险、汽车等主体和活动叠加行业规则 |

箭头只表示阅读关系，不表示只有一部上位法或必须顺序履行。

**跨境规则组合使用。** [2024年规定第13条][src-crossborder]明确，此前安全评估和标准合同办法与其不一致的适用该规定；免于三项出境程序不等于免除个人信息和数据安全义务。

**报告按接收部门分别判断。** [国家事件报告办法][src-national-report]与[人民银行2025年第4号令][src-pbc-report]的主体、分级和时限不同。向人民银行报告不当然替代网信、公安、关基或其他行业义务。

**金融文件先辨主体。** [2020年监管数据办法][src-regulatory-data]管理监管部门及受托机构的监管数据活动；[2024年银行保险机构数据办法][src-bank-data]面向机构的数据处理活动，不能因名称接近混用。

| 违法向境外提供重要数据，[第46条][src-dsl] | 改正、警告，可并罚10万—100万元；严重档100万—1000万元，可暂停业务、停业整顿、吊销许可执照 | 一般档可罚1万—10万元；严重档10万—100万元 |

### 金额之外的责任适用

行政处罚、监管措施、合同终止与民事赔偿不能合并称为罚款；涉嫌犯罪的行政罚款不代替刑事责任。分别核对[行政处罚法第8、9、27条][src-administrative-penalty]和[个保法第64、66、69—71条][src-pipl]。

[行政处罚法第29条][src-administrative-penalty]规定同一违法行为不得给予两次以上罚款，违反多个规范应罚款时按罚款数额高的规定处罚；多个独立行为、单位和个人责任仍按事实判断，不能机械叠加各上限。

[第37条][src-administrative-penalty]涉及行为发生时规定与后来较轻或不认为违法规定的适用，2026年新罚则不能无条件追溯此前行为。[第32—33条][src-administrative-penalty]及[人民银行3号令第52条][src-pbc-data]等涉及从轻、减轻或不予处罚的具体条件。保存真实履职、监测、整改和报送证据，不能预设内部免责必然约束行政机关。
