# APPI 日本个人信息保护法

日本业务应按APPI的对象、角色和触发条件建立个人信息控制。中国个保法和GDPR中的分类、同意及事件时钟，不能直接搬到日本。本文依据PPC公布的[法律体系](https://www.ppc.go.jp/en/legal/)、[通则指南](https://www.ppc.go.jp/personalinfo/legal/guidelines_tsusoku/)和[外国第三方提供指南](https://www.ppc.go.jp/personalinfo/legal/guidelines_offshore/)，日文正式文本为准，英文译文辅助理解。

## 先区分数据对象和使用目的

个人信息、个人数据、保有个人数据以及要配虑个人信息（需特别注意的个人信息）有不同定义和义务。不能直接把中国“敏感个人信息”标签作为日本法上的最终分类，也不能因数据来自公开网页而自动免除处理责任。

| 事项 | 主要依据 | 验收示例 |
| --- | --- | --- |
| 利用目的、适当取得及通知公示 | 第17—21条等 | 实际收集字段、用途及公开说明一致 |
| 安全管理 | 第23条 | 权限、保护、恢复等措施与数据风险相匹配 |
| 员工和受托方监督 | 第24—25条 | 真实权限、监督和退出记录可核验 |
| 第三方提供 | 第27条等 | 逐项判断同意、法定例外和相应记录 |
| 保有个人数据等权利 | 第32条及后续条款 | 按各项条件受理、执行或说明理由 |

这些是阅读定位，具体定义、例外和适用条件以正式文本及指南为准。

## 委托、共同利用与境外提供分开判断

国内委托和满足条件的共同利用，并不天然等同于普通第三方提供；仍需履行相应监督、告知或其他条件。第28条对向外国第三方提供另有规则，应判断取得必要信息后的本人同意、认可的地区或保障安排等路径，以及对应持续义务。

**实施建议。** 记录接收方的法律实体、国家地区、目的、实际访问、再委托和保护安排。境外客服、远程运维及云服务应按真实可访问和处理情况分析，不只检查服务器地址；国内委托例外不能被直接当作境外提供豁免。

**例子。** 日本应用将故障日志发送给境外分析服务，日志内仍包含可识别用户的记录。应判断该接收和处理关系、跨境条件及保存范围，不能因为名称叫“技术日志”就不进入个人信息治理。

## 泄露报告先核对四类触发条件

依据第26条、施行规则第7条及通则指南3-5节，达到相应情形的泄露、灭失、损毁或其发生之虞，需要进入报告判断。

| 条件 | 核对重点 |
| --- | --- |
| 含要配虑个人信息的个人数据 | 根据日本法定义判断，不仅靠内部标签 |
| 不当利用可能造成财产损害的个人数据 | 支付凭据等实际危害，不限于医疗等类别 |
| 有不正当目的行为导致或可能导致 | 覆盖相关外部或内部行为，不能只看是否超过人数门槛 |
| 涉及本人数量超过1000人 | 按自然人数量核对，不能用记录条数替代 |

关于高度加密等保护措施的排除应按规则和指南逐项核验，不能把“使用过加密”直接作为免报条件。

**边界例子。** 800人的数据被恶意窃取，虽未超过1000人，仍可能因不正当目的行为满足独立触发条件。发生之虞同样需要判断，不能等全部下载事实最终查清。

## 速报、确报和本人通知分别跟踪

| 任务 | 规则与口径 | 实施证据 |
| --- | --- | --- |
| 速报 | 知悉后迅速报告；指南对“迅速”给出通常约3—5日的参考，不能理解为可一律等到第5日 | 最初知悉、已知内容、提交和补充 |
| 确报 | 通常知悉之日起30日内；规则第7条第3项的不正当目的行为情形为60日内 | 触发类型、起算依据、报告版本和回执 |
| 本人通知 | 根据事态迅速通知；困难时的替代措施按法定条件判断 | 对象、必要内容、方式或替代依据 |

通则指南说明，法人以任一部门知悉的时点为基准；确报计算以该日为第一日，包含周末及节假日，截止日的顺延另按其规则。不能全部改算工作日，也不能套用GDPR的72小时。

受托方按法定条件迅速通知承担报告义务的委托方时，存在由委托方报告的例外安排；受托方仍需调查并协作。不能仅凭合同写“客户负责报告”就自动免责。

## 一次完整的企业验收

从一个测试账号追踪数据目的、采集、权限、受托方、境外访问与删除；再用合成泄露事件验证四类触发、速报和确报时钟、本人通知及委托协同。保存未知信息和判断变化，不用事后修改获知时间使流程看起来合规。

报告入口与操作说明见[PPC泄露应对页面](https://www.ppc.go.jp/personalinfo/legal/leakAction/)。支付或其他金融业务还需结合[FSA网络安全要求](https://www.fsa.go.jp/policy/cybersecurity/index.html)和具体牌照规则，APPI报告不替代行业事件义务。
