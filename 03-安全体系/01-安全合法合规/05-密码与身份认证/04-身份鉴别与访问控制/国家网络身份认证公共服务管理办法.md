# 国家网络身份认证公共服务管理办法

接入网号、网证时，应分别确认实名义务、用户选择和实际获取字段。接入成功仅证明相应身份核验完成，不能替代业务授权、反诈和个人信息保护。本文依据[六部门令第173号](https://www.cac.gov.cn/2025-05/23/c_1749711107835487.htm)，测试方法为实施建议。

## 法规概览

| 项目 | 内容 |
| --- | --- |
| 公布与施行 | 2025年5月19日公布，2025年7月15日施行 |
| 网号 | 与身份对应、不含明文身份信息的网络身份符号 |
| 网证 | 承载网号及非明文身份信息的认证凭证 |
| 关键角色 | 申领和使用者、公共服务平台、接入的互联网平台或相关行业 |

## 安全要求与实施

### 自愿申领、接入和同等服务

**法规要求｜第4—7条。** 自然人自愿申领；推广应用和互联网平台接入遵循自愿原则。有关主管部门、重点行业保留其他合法核验方式；互联网平台保障通过其他方式完成身份核验的用户享有同等服务。

**验收示例。** 两个测试账号分别采用网号网证和其他合法实名路径，比较核心功能、价格、权益及投诉入口。接入方不得用不合理降级迫使用户申领。公共服务暂时不可用时的降级方式应维持业务本身的实名要求，不能退回未经核验的“输入姓名即可通过”。

### 已通过核验后，不重复索取无必要的明文身份

**法规要求｜第7—8条。** 用户选择网号网证并通过验证后，原则上不得再要求明文身份信息，法律、行政法规另有规定或用户同意提供的除外。依法核验但无需留存证件信息时，公共服务平台仅提供结果；依法确需取得、留存证件信息时，经用户授权或单独同意按最小化原则提供。

| 接入场景 | 设计检查 | 可验证证据 |
| --- | --- | --- |
| 仅需核验身份 | 接口优先处理核验结果及必要关联标识 | 返回字段、数据库结构、日志脱敏 |
| 确需证件信息 | 记录法律依据、用途、字段和授权 | 业务适用判断、授权记录和访问控制 |
| 再处理或对外提供 | 判断第8条及个保法等对应条件 | 接收方、用途、单独同意或例外依据 |
| 排障与分析 | 不把证件或认证凭证默认写入日志 | 真实日志抽样、导出权限和保存策略 |

“网号不含明文身份”不意味着其关联数据可以任意处理；仍应结合可识别性与实际用途判断个人信息义务。

### 区分未成年人申领与使用

| 年龄和动作 | 第4—5条要求 | 接入验证 |
| --- | --- | --- |
| 不满十四周岁申领 | 监护人同意并代为申领 | 对接公共服务核验结果，不自行假定已完成监护步骤 |
| 已满十四周岁未满十八周岁申领 | 在监护人监护下申领 | 正确承接年龄及适用场景保护 |
| 不满十四周岁使用网号网证核验 | 取得监护人同意 | 业务侧保留适用同意及核验关联 |

实名认证结果不能证明用户在任何业务中都具有相应民事行为能力。消费、未成年人模式和个人信息处理仍需依业务规则判断。

### 公共平台义务与接入方义务分别落地

第9条等规定公共服务平台的最小必要收集、用途限制、告知同意、删除等要求；后续条款规定其安全保护和相关管理要求。企业作为普通接入方，不应把公共平台的所有法定责任直接复制成自身义务，也不能据此免除自身系统安全责任。

**实施建议。** 接入方应验证请求来源、回调签名、会话绑定、有效期、重放防护和凭证访问权限。一次成功回调只允许完成对应账户、对应流程的核验，不能跨账号复用；认证服务不可用、回调失败和撤销等异常应有受控处置。

## 一次完整验收

用合成身份和测试环境执行：正常核验、其他合法路径、拒绝额外明文字段、未成年人使用、回调重放、跨账户回调及服务不可用。每项保留输入条件、请求关联号、接口字段、决策和结果。通过条件是身份绑定正确、字段最小化、适用同意可追溯、同等服务真实存在，且异常不会绕过身份核验。
