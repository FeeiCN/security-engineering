# 数据出境安全评估办法

本文用于指导依法需要申报数据出境安全评估的场景。**具体触发阈值必须同时核对2024年《促进和规范数据跨境流动规定》；与本办法原始门槛不一致的，适用后发布的规定。**

[法规概览](#overview) · [安全要求与实施](#requirements) · [法规原文](#reference)

## 法规概览 {#overview}

| 项目 | 内容 |
| --- | --- |
| 法规 | 《数据出境安全评估办法》，国家互联网信息办公室令第11号 |
| 生效日期 | 2022年9月1日 |
| 主要适用场景 | 依法应申报安全评估的重要数据、个人信息等数据出境活动 |
| 核心问题 | 申报触发、出境风险自评估、申报材料、监管评估、结果有效期、重大变化后的重新申报 |
| 官方来源 | [国家互联网信息办公室](https://www.cac.gov.cn/2022-07/07/c_1658811536396503.htm) |

下文按 **“法规要求 → 落实与验收”** 展开：每项要求同时说明实施动作与可验证证据。

## 安全要求与实施 {#requirements}

### 正确识别安全评估触发场景

**法规要求｜第4条及现行跨境配套规则。** 重要数据、关键信息基础设施运营者及达到现行数量门槛的个人信息出境活动，可能需要申报数据出境安全评估。

**落实与验收。**

- 先识别关基身份和重要数据，再按现行规则统计个人信息、敏感个人信息出境规模。
- 统一跨业务、跨系统统计口径，不通过拆分项目、主体或接收方规避评估。
- 2024年后路径判断优先核对《促进和规范数据跨境流动规定》，不能继续机械使用2022年办法的旧数量门槛。
- 每条跨境数据流记录路径判断和适用依据。

**验收证据。**

- 随机抽一条未申报安全评估的数据流，为什么不触发，依据哪一版规则？
- 重要数据判断是谁做的，是否有行业目录和事实依据？
- 全公司年度累计出境规模与各业务申报口径能否对上？
- 是否存在业务拆分后每条都低于门槛、合计却应触发评估的情况？

### 在申报前完成数据出境风险自评估

**法规要求｜第5条。** 数据处理者申报前应开展数据出境风险自评估，重点评估出境和接收方处理活动的合法正当必要性、数据规模和敏感程度、境外风险、接收方能力、合同责任和权益保障等。

**落实与验收。**

- 自评估使用真实数据字段、处理目的、传输架构、接收方、保存地点、权限和安全措施。
- 对重要数据和个人信息分别识别风险，不能用通用问卷代替实质分析。
- 评估发现项进入架构、字段、合同和技术控制整改，整改后复测。
- 评估结论与正式申报材料保持一致。

**验收证据。**

- 抽一份自评估，能否逐字段对上生产接口和实际接收方？
- 评估发现过什么风险，是否真正改变过方案？
- 接收方再提供、泄露处置、个人权利等风险是否有具体控制？
- 自评估是申报前完成还是项目上线后补做？

### 准备完整、真实、一致的申报材料

**法规要求｜第6条等。** 申报应提交申报书、数据出境风险自评估报告、与境外接收方拟订立的法律文件等材料，并对材料真实性负责。

**落实与验收。**

- 建立申报材料版本库，确保主体、目的、数据范围、数量、接收方、保存期限和安全措施在各材料中一致。
- 法律文件明确数据安全责任、事件通知、监督、再提供、删除/返还和终止后的处理要求。
- 申报期间业务重大变化必须同步更新，不以“已经递交”为理由继续使用失真的材料。

**验收证据。**

- 对比申报书、自评估、合同和生产配置，字段/数量/接收方是否一致？
- 监管问询的数据能否从原始系统快速复核？
- 申报期间业务发生变化时，是否主动更新材料或向监管说明？

### 配合监管评估并落实附加要求

**法规要求｜第8—14条等。** 网信部门从国家安全、数据安全、个人信息权益、境外政策环境等因素开展评估；数据处理者应配合并对相关问题作出说明。

**落实与验收。**

- 设立统一申报负责人和跨部门响应机制，监管补充材料请求能够及时分派、复核和回复。
- 对监管提出的风险、限制和附加措施形成任务，落实到系统、合同和业务运行。
- 审批结果与具体出境范围绑定，业务不能将一个评估结果泛化到未覆盖的数据流。

**验收证据。**

- 最近一次监管补件由谁组织，回复事实是否经过技术和法务双重核对？
- 评估通过时附带的约束是否进入生产控制和合同？
- 同一结果是否被多个未纳入申报范围的新业务“借用”？

### 管理评估结果有效期和重新申报

**法规要求｜本办法及2024年配套规定。** 现行规则下，安全评估结果有效期为3年，符合条件时可申请延长；出境目的、方式、范围、接收方等发生法定变化时，应重新判断是否需要申报。

**落实与验收。**

- 维护结果生效日、到期日、适用范围和延长申请窗口。
- 业务变更、接收方变化、数据规模/种类变化、境外环境变化纳入重新申报触发机制。
- 申请延长前核对实际出境是否仍与原评估一致。

**验收证据。**

- 哪些评估结果未来一年到期，延长/重新申报计划是什么？
- 原评估覆盖的数据范围与今天的真实出境是否仍一致？
- 最近一次重大变更有没有触发重新评估判断？
- 到期后是否存在继续出境但手续尚未完成的情况？
